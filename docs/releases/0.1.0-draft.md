# Code Atlas 0.1.0 — unreleased readiness draft

**Status:** Not released. This document records the current source and local
package preflight as of 21 October 2026. It is a review draft, not a download
announcement or a claim that the release gates have passed.

## What is in this build

- Local repository inventory, bounded immutable snapshots, Atlas, Code Lens,
  and a local parser-backed symbol and relationship index.
- File-by-file guide planning, chapter editing and review, revision history,
  and a manually paced Walkthrough with source-linked citations and typed
  visual hotspots.
- Read-only comparisons between Git commits already present locally, with
  reviewed, optional provider-backed PR Guides and transient single-hunk
  explanations.
- A single-file HTML export for selected accepted guide revisions. It can
  include reviewed transcripts and cached narration audio, but it is not a
  Code Atlas project backup.
- Optional, explicitly reviewed direct API requests to the Gemini, OpenAI,
  and Anthropic APIs. Gemini speech synthesis is a separate optional request
  path. Local browsing, snapshots, indexing, and saved-guide review do not
  require an API key.

These are implemented source workflows. The packaged app and each workflow
still have outstanding native, provider, content-quality, and release
acceptance gates described below.

## Parser and index coverage

The local symbol and relationship index recognizes a defined subset of:

- Rust: `.rs`
- TypeScript: `.ts`, `.tsx`, `.mts`, `.cts`
- JavaScript: `.js`, `.jsx`, `.mjs`, `.cjs`

Other paths remain visible in the inventory, but do not contribute parser-backed
symbols or relationships. The index is static syntax evidence, not a complete
runtime call graph. Parser errors, unsupported syntax, stale hashes, and bounded
index results are reported rather than presented as complete evidence.

Snapshot capture is bounded to 2 MiB per file, 100 MiB total, 25,000 paths,
1,024 UTF-8 bytes per path, and 1,000 directory entries per directory. The
index is separately bounded to 5,000 files, 1 MiB per source file, 50 MiB of
source, 250,000 syntax-tree nodes per file, and 64 MiB of serialized index
data. Capture excludes configured generated/build/cache directories, Git-ignored
paths (except tracked ignored files), symlinks and their targets, `.git`
contents, nested repositories, and non-regular filesystem objects. See the
source-backed [first-session guide](../GETTING_STARTED.md) and
[interaction contract](../INTERACTION_CONTRACT.md) for workflow behavior.

## Provider disclosure snapshot

The static direct-text disclosure records in the source were checked on
13 October 2026. They currently name Gemini 3.8 Flash and Gemini 3.5 Flash-Lite,
GPT-6 Luna, and Claude Haiku 5.5. The separate narration record names Gemini
3.8 Flash-Lite TTS and was also checked on 13 October 2026. These model names,
prices, and terms are release metadata, not live checks of service availability,
account tier, quota, billing, region, or eligibility. Recheck first-party terms
and pricing before any distribution or provider request. A listed free tier
does not guarantee that a particular request is free or available.

Provider-backed requests require explicit provider/model selection, review of
the exact request and applicable disclosures, and user consent. Direct API
keys are stored in macOS Keychain. The app does not automatically switch
providers or models. Coding-agent backends are not selectable in this build.

## Known limitations and open release gates

- This checkout does not provide a signed and notarized installer or a user
  download. The local `.app` and `.dmg` preflight is unsigned; it is not a
  distributable release artifact.
- The app bundle declares macOS 14.0 as its minimum, matching the selected
  Apple Silicon Pocket TTS runtime wheel. This is a declared packaging floor,
  not clean-account compatibility evidence. Cargo `rust-version` remains
  unset; the crate uses the Rust 2024 edition, whose compiler floor is Rust
  1.85, and compatibility of the locked dependencies with 1.85 has not been
  verified. Clean-account installation, Keychain, offline, VoiceOver,
  keyboard, zoom/reflow, contrast, and motion acceptance remain to be
  completed in the packaged native app.
- Live provider availability and eligibility, production TLS/proxy behavior,
  complete provider response parsing, cancellation after provider receipt,
  and manual disclosure review have not passed acceptance. The app cannot
  verify a user's account tier, quota, region, age, or billing settings.
- Human review of generated chapter quality and TTS pronunciation, pacing, and
  naturalness remains required. Automated/source-level checks do not establish
  that explanations are accurate or narration sounds acceptable.
- Stale guide updates operate on one section per request; there is no
  multi-section regeneration request. Coding-agent integrations are planned,
  not implemented as selectable backends.
- Offline HTML export is a reader copy. There is no complete application
  backup, restore, or import workflow.
- The owner selected MIT for Code Atlas-authored source. The app package still
  needs a complete, verified third-party dependency notice inventory before
  redistribution; generated explanations, captured repositories, and
  evaluation/design artifacts have separate or unverified terms.

See the [Kata backlog](../KATA_BACKLOG.md) for the task contracts and current
acceptance evidence. Do not treat a source implementation or local package
build as proof that an open gate has passed.
