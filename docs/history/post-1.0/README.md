# Deferred post-1.0 scope

These task definitions are preserved for possible future planning. They are not
part of the active first-release backlog. The first release is Codex-first and
focuses on reliable, source-grounded code explanations, useful visuals,
incremental reading, local narration, and a dependable Mac release.

On 8 November 2026, the user asked to trim nonessential work from the active
task list. The following Kata issues were soft-deleted so they can be restored
if this work is scheduled later:

- `hsn3`, `tbng`, `a9v9`, and `qjm3`: local PR Guide follow-up.
- `c8nz`: direct model API catalog.
- `tpta`, `8gqw`, `m00g`, and `mfz2`: non-Codex agent integrations and the wider
  backend catalog.

Standalone offline export (`8r4j`) was already absent from the live Kata issue
list and is archived here as well. Formal accessibility-audit work is not in
the active backlog. Ordinary keyboard use, clear controls, and readable themes
remain baseline usability requirements; no separate audit matrix is required.

On 9 November 2026, full Guide revision compare/restore (`gace`) and
generation-time narration prewarming (`tp6r`) were also removed from the active
0.1 backlog. Selective one-section repair (`tbsh`) and local Pocket playback
with cached replay (`dbmd`) remain first-release work. These two enhancement
definitions are preserved in this archive; restore a Kata issue before
scheduling them: [Guide revision comparison and restore](21-revision-history.md)
and [narration prewarming](75-narration-prewarm.md).

On 8 November 2026, the standalone generation-stage timing task (`ps02`) was
soft-deleted. Guide generation has no elapsed-time SLA or automatic timeout;
the reader sees concise progress and can stop work. Detailed timing benchmarks
and a user-facing diagnostics surface are not first-release features. The old
task definition remains archived as historical research in
[`71-generation-timing-traces.md`](../71-generation-timing-traces.md).

Restore the relevant Kata issue before treating any archived definition as
scheduled work. Historical research and acceptance notes remain unchanged.
