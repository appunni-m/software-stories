# Support

Code Atlas is an unreleased, in-progress macOS application. For usage
questions, bug reports, or feature requests, search the
[existing GitHub issues](https://github.com/appunni-m/software-stories/issues)
and open an issue with the relevant category. Include the app version, macOS
version, steps to reproduce, and a concise description of what you expected
and saw. Do not attach private source code, credentials, customer data, or
repository snapshots that you are not allowed to share.

There is no published support window or response-time guarantee. Issues are
reviewed as maintainer time allows; filing one does not imply that it will be
accepted or fixed.

For security concerns, read [Security reporting](SECURITY.md) first. The project
does not currently publish a verified private reporting route. Do not disclose
unpatched vulnerability details in a public issue.
