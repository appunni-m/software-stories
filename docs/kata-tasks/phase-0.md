## Goal
Establish the product's visual and interaction contract, then build one Mac shell in which Atlas, Code Lens, Walkthrough, Guide Plan, and Chapter Studio feel like connected parts of one app.

## Gate
The app opens without a repository, account, API key, or provider call. Navigation and empty/error states are clear. The screen hierarchy follows the approved concepts and one shared project/snapshot selection.

## Child issues
- `01-product-experience.md` defines the screen and interaction contract.
- `02-desktop-shell.md` implements the empty but navigable app.
